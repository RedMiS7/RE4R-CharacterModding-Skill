# 模型、骨架与蒙皮

## 1. 坐标与比例策略

分别确认源模型、目标资源解析器和制作软件的单位、轴向、矩阵布局与对象变换。用已知位置／方向完成往返检查。位置对齐不等于旋转轴和骨 roll 正确。

构建前决定当前任务的比例策略：保留源比例、适配目标动画比例，或限定区域的局部修正。记录由谁定义外形、核心动画 rest 与物理分支位置。

- 先建立一个明确的源到目标坐标变换，缩放和位移只应用一次。
- 保留源比例时，代表性目标动画的平移也要检查；静止外形正确不保证动画中的颈、躯干和四肢比例稳定。
- 分段拟合必须同时验证段长、轴向与连接连续性，不能用每骨独立拉伸替代完整比例策略。
- 局部刚性部件按整体几何包及所属专用骨分支共同变换。跨段衣物保留归一化的混合权重。

对象父级、旧 parent inverse、Armature modifier、缓存 bind/rest 属性与最终骨架保持一致。明确哪些由当前工具重算；不要混用旧导出缓存和新 rest。

## 2. 骨骼映射

从当前模型生成映射表，逐骨记录源骨、目标骨、用途、父级、世界／局部 rest、是否加权及是否被控制资源引用。

区分核心动画骨、变形物理骨、挂点、末端和兼容控制骨。每个正权重、Chain、碰撞或控制引用的骨都要有完整父级闭包。多对一合并需记录被减少的空间变形自由度。

当前动画合同决定核心骨的名称、层级和方向。源物理骨添加到已证明的挂点，配套重建框架。没有当前 consumer 证据时，不额外添加控制资源或共享骨架覆盖。

对普通物理 dummy 末端验证零正权重；源定义的有权重端点要保留其真实角色。第一根可见且有权重的骨不一定是第一根模拟骨。

## 3. 权重

根据当前格式与工具决定最大影响数。截断后重新归一化，拒绝未加权顶点，检查量化误差和无效索引。检查每个正权重与骨枢轴的关系，不只检查主权重。

权重转移应在对应的解剖／部件范围内进行。邻近位置不一定属于相同语义，尤其是嘴唇、上下眼睑、左右手指和相贴衣层。记录未映射与歧义顶点，不以全局最近点悄悄兜底。

对局部修复输出顶点白名单和实际变化；按影响范围验证非目标 UV、索引、材质、几何和其他权重不变。裙子问题进入 [部件问题库](../../re4-mod-repair/references/component-problems.md)。

## 4. 面部动画准备

先证明当前目标如何加载面部，以及身体、面部和骨架的实际配对。源模型静态脸和目标面部动画可能有不同层级与 rest，不按身体绑定成功推断面部成功。

1. 分别盘点眼球、眼睑、眉、嘴唇、下颌等源几何与目标可用驱动。
2. 用当前模型的坐标与骨枢轴建立映射；保留相关父级与所需控制关系。
3. 静态外形、面部蒙皮、动作资源采样和游戏内表现分别检查。
4. 验证闭眼与睁眼、下颌开合、嘴唇连续性和视线；未获得的动作／解析器明确记为未验证。

只有静态形态键的源模型不能被宣称已自动转换为完整的目标骨骼表情。按目标合同选择可执行方案；不能通过关闭面部 consumer 掩盖加载或绑定问题。

## 5. 导出检查

按当前 consumer 分别构建身体、面部、头发和辅助输出。源对象序号不能直接决定运行可见组或材质索引。

导出后独立读取：

- 顶点／三角形和材质三角形集合；声明了拓扑修改时使用对应的变化范围。
- UV 各位置流、法线、边界、有限数值和未预期的形变。
- 骨名、父级、rest/bind、逆矩阵、加权骨映射与完整闭包。
- 每顶点的正权重组、归一化与量化误差。
- 模型骨架与独立 skeleton／控制资源是否一致。

代表姿态至少覆盖当前修复涉及的关节或部件。静止截图、权重和为一、工具导出成功各自只能证明相应局部条件。
